# RateMyProfessor Analysis (NYU Capstone)

This project is my NYU Data Science capstone analyzing professor ratings from RateMyProfessor.

## Overview
The analysis explores relationships between professor ratings, difficulty, tags, and course characteristics using statistical testing and machine learning techniques.

## Files
- `CapProject.py` – full analysis and modeling pipeline
- `CapstoneProject.pdf` – final written capstone report

## Methods
- Data cleaning and preprocessing
- Exploratory data analysis
- Statistical hypothesis testing
- Predictive modeling and evaluation

## Tools
Python, pandas, numpy, matplotlib, scikit-learn

## Context
Completed as part of the NYU Data Science capstone project.
